# Everything_Mew v0.2.0-rc.1 Release Notes / 릴리스 노트

Status: prerelease candidate dated 2026-07-17. The Python package version is
`0.2.0rc1` and the Git tag is `v0.2.0-rc.1`.

상태: 2026-07-17 시험 배포 후보입니다. Python 패키지 버전은 `0.2.0rc1`,
Git 태그는 `v0.2.0-rc.1`입니다.

## English

### Summary

Version 0.2 introduces a direct, low-standby stdio MCP runtime for Codex Desktop
and other hosts that keep one local server process per active session. The lite
runtime does not require FastAPI or FastMCP, and it defers loading the Everything
backend until the first tool call. The existing FastMCP commands remain
available as a compatibility path.

### Highlights

- Add `everything-mew-lite`, `everything-mcp-lite`, and
  `python -m everything_mcp.lite_stdio` entrypoints.
- Keep package import lightweight and expose only four read-only MCP tools.
- Align initialization, notifications, request IDs, schemas, and tool errors
  with the MCP 2025-11-25 protocol boundary used by the lite runtime.
- Replace the unbounded synchronous SDK query with the official asynchronous
  reply-window flow and a 15-second deadline.
- Serialize process-wide SDK state, allocate non-reused reply IDs, reject stale
  replies after Windows handle reuse, and retain failed callback cleanup for
  safe retry.
- Parse OR branches, grouping, quoting, and negation before broad-query checks;
  reject malformed, universal, content-heavy, and insufficiently narrowed regex
  branches before calling a backend.
- Use Everything 1.4.1 core syntax as the default profile. Known Everything 1.5
  content/ADS aliases, `content*:` literal-tail forms, nested content modifier
  chains, and `from-disk:` require a non-root scope plus a separate indexed
  filter.
- Compose `C:\Work\project` scope as `"C:\Work\project\"`, verify returned
  paths against that boundary, and exclude prefix siblings.
- Make `everything_count` request zero result fields with `Everything_SetMax(0)`
  before reading the total, avoiding unnecessary path materialization.
- Decode ES metadata CSV as UTF-8 and retrieve SDK paths with the documented
  required-length call, including the 32,767-character Windows boundary.
- Add Windows CI for Python 3.11 and 3.14, strict mypy, Ruff, wheel/sdist builds,
  installed-wheel protocol smoke tests, and multi-session memory evidence.
- Add reproducible release, contribution, installation, and private security
  reporting guidance in English and Korean.

### Compatibility and upgrade

- Supported runtime: Windows with CPython 3.11 through 3.14.
- The public tool names and response contracts remain compatible with 0.1.
- Existing `everything-mew` and `everything-mcp` commands remain available when
  the `[server]` extra is installed.
- For always-enabled hosts, change the command to `everything-mew-lite` or
  `python -m everything_mcp.lite_stdio`.

```powershell
py -m pip install --upgrade .
```

Install FastMCP compatibility only when required:

```powershell
py -m pip install --upgrade ".[server]"
```

### Known limitations

- Everything_Mew remains Windows-only and requires a running standard Everything
  installation. Everything Lite does not provide the required IPC interface.
- The SDK backend requires a trusted `Everything64.dll` or `Everything32.dll`
  matching the Python process architecture.
- A host may still create one lite process per active session. Version 0.2 lowers
  per-process standby memory; host session cleanup still controls process count.
- HTTP is not required or enabled automatically.

### Final live validation

- An isolated installation of the candidate wheel ran the lite MCP JSON-RPC
  lifecycle and queried a live Everything 1.4.1.1032 index with
  `size:>100mb`.
- `everything_count` returned 1,005. An independent SDK oracle fetched all
  1,005 entries; every path was unique, every size exceeded 100 MiB, and the
  list was sorted by size.
- The public 100-item search page exactly matched the first 100 SDK oracle
  entries, including path and size. The machine-specific path report remains
  local and is intentionally excluded from source and distribution archives.

## 한국어

### 요약

0.2는 Codex Desktop처럼 활성 세션마다 로컬 서버 프로세스를 유지하는 호스트를
위해 직접 구현한 낮은 대기 메모리 stdio MCP 런타임을 도입합니다. lite
런타임은 FastAPI나 FastMCP를 요구하지 않고 첫 도구 호출 전까지 Everything
백엔드 로드를 지연합니다. 기존 FastMCP 명령은 호환 경로로 유지합니다.

### 주요 변경 사항

- `everything-mew-lite`, `everything-mcp-lite`,
  `python -m everything_mcp.lite_stdio` 진입점을 추가했습니다.
- 패키지 import를 가볍게 유지하고 읽기 전용 MCP 도구 네 개만 노출합니다.
- lite 런타임의 초기화, notification, 요청 ID, 스키마, 도구 오류를 MCP
  2025-11-25 프로토콜 경계에 맞췄습니다.
- 무제한 동기 SDK 쿼리를 공식 비동기 응답 창 흐름과 15초 제한으로
  교체했습니다.
- 프로세스 전체 SDK 상태를 직렬화하고 재사용하지 않는 응답 ID를 할당하며,
  Windows 핸들 재사용 뒤의 오래된 응답을 거부하고 콜백 정리 실패 객체를
  안전한 재시도까지 보존합니다.
- 광범위 쿼리 검사 전에 OR 분기, 그룹, 인용, 부정을 파싱하고 잘못된 문법,
  전체 일치, 고비용 콘텐츠, 충분히 축소되지 않은 정규식 분기를 백엔드 호출
  전에 거부합니다.
- Everything 1.4.1 핵심 문법을 기본 프로필로 사용합니다. 알려진 Everything
  1.5 content/ADS 별칭, `content*:` literal-tail 형식, 중첩 content modifier
  체인, `from-disk:`는 루트가 아닌 scope와 별도 인덱스 필터를 요구합니다.
- `C:\Work\project` scope를 `"C:\Work\project\"`로 합성하고 반환 경계를
  다시 검증해 접두사가 같은 형제 경로를 제외합니다.
- `everything_count`는 `Everything_SetMax(0)`과 request flag 0을 사용한 뒤
  total만 읽어 불필요한 경로 목록 생성을 피합니다.
- ES 메타데이터 CSV를 UTF-8로 디코딩하고 32,767자 Windows 경계를 포함해
  문서화된 필요 길이 호출로 SDK 경로를 가져옵니다.
- Python 3.11·3.14 Windows CI, strict mypy, Ruff, wheel/sdist 빌드, 설치 wheel
  프로토콜 스모크, 다중 세션 메모리 증거 검증을 추가했습니다.
- 재현 가능한 릴리스, 기여, 설치, 비공개 보안 신고 안내를 한영으로
  보강했습니다.

### 호환성과 업그레이드

- 지원 환경은 Windows의 CPython 3.11부터 3.14까지입니다.
- 공개 도구 이름과 응답 계약은 0.1과 호환됩니다.
- `[server]` 선택 사항을 설치하면 기존 `everything-mew`와
  `everything-mcp` 명령을 계속 사용할 수 있습니다.
- 항상 켜 두는 호스트에서는 명령을 `everything-mew-lite` 또는
  `python -m everything_mcp.lite_stdio`로 변경하세요.

```powershell
py -m pip install --upgrade .
```

FastMCP 호환 기능이 필요할 때만 다음과 같이 설치합니다.

```powershell
py -m pip install --upgrade ".[server]"
```

### 알려진 제한 사항

- Everything_Mew는 Windows 전용이며 표준 Everything이 실행 중이어야 합니다.
  Everything Lite는 필요한 IPC 인터페이스를 제공하지 않습니다.
- SDK 백엔드는 Python 프로세스 비트수와 맞는 신뢰할 수 있는
  `Everything64.dll` 또는 `Everything32.dll`이 필요합니다.
- 호스트는 활성 세션마다 lite 프로세스를 하나씩 만들 수 있습니다. 0.2는
  프로세스별 대기 메모리를 줄이지만 프로세스 수는 호스트의 세션 정리에
  달려 있습니다.
- HTTP는 필요하지 않으며 자동으로 활성화하지 않습니다.

### 최종 실환경 검증

- 후보 wheel을 격리 설치한 뒤 lite MCP JSON-RPC 수명 주기를 실행하고 실제
  Everything 1.4.1.1032 인덱스에서 `size:>100mb`를 검색했습니다.
- `everything_count`는 1,005를 반환했습니다. 독립 SDK 원본 조회도 1,005건을
  가져왔고 모든 경로가 고유하며 모든 크기가 100 MiB를 초과하고 크기순으로
  정렬된 것을 확인했습니다.
- 공개 검색의 첫 100건은 경로와 크기를 포함해 SDK 원본의 첫 100건과 정확히
  일치했습니다. 컴퓨터별 경로가 포함된 보고서는 로컬에만 보관하며 소스 및
  배포 아카이브에서 의도적으로 제외합니다.
