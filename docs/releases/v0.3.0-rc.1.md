# Everything_Mew v0.3.0-rc.1 Release Notes / 릴리스 노트

Status: prerelease candidate dated 2026-08-13. The Python package version is
`0.3.0rc1` and the Git tag is `v0.3.0-rc.1`.

상태: 2026-08-13 시험 배포 후보입니다. Python 패키지 버전은 `0.3.0rc1`,
Git 태그는 `v0.3.0-rc.1`입니다.

## English

### Summary

Version 0.3 changes the recommended Codex integration from a session-scoped
MCP server to a bounded one-shot command. Each tool request starts a short-lived
process tree, returns one existing read-only tool result, and exits. OpenCode
and manual MCP hosts can continue using the lite stdio compatibility server.

### Highlights

- Add `everything-mew-once`, `everything-mcp-once`, and
  `python -m everything_mcp.oneshot` entrypoints without a FastMCP dependency.
- Accept exactly one UTF-8 JSON request envelope, bounded to 65,536 bytes, and
  reject trailing data, malformed input, unknown tools, and invalid arguments.
- Preserve the four public read-only tool contracts and reuse the existing lite
  dispatcher instead of maintaining a second tool implementation.
- Use exit `0` for success, exit `1` for a published tool error, and exit `2`
  when invocation output must not be trusted.
- Make the Codex skill call the resolved one-shot runner while the retained MCP
  registration remains disabled as an explicit rollback configuration.
- Pin and validate absolute runner and SDK DLL paths. The installer safely
  escapes apostrophes before inserting paths into PowerShell literals.
- Keep `everything-mew-lite` and `everything-mcp-lite` unchanged for OpenCode
  and manual MCP compatibility.

### Validation

- 422 pytest cases, Ruff, and strict mypy across 31 source and test files passed
  on local Python 3.11.
- Wheel and source archives built successfully; archive contents excluded SDK
  binaries, `.env` files, credentials, caches, and local evidence.
- An isolated wheel installation exposed both one-shot commands and completed
  syntax, status, and search smoke tests without FastAPI or FastMCP.
- Live SDK status reported Everything 1.4.1.1032, `sdk-ipc`, a loaded database,
  and the expected x64 target.
- Ten sequential and six concurrent live one-shot searches completed without a
  surviving Everything_Mew process. A real Windows reboot also left zero idle
  Everything_Mew Python processes before and after the calls.
- Independent review found no remaining Critical or Important issue.

On the acceptance host, ten active one-shot process-tree snapshots had a median
of 33.74 MiB working set and 15.15 MiB private memory including the temporary
console host. Six simultaneous calls used 202.34 MiB working set and 91.06 MiB
private memory in aggregate. These are host-specific observations, not fixed
resource guarantees. Idle Codex sessions retain no Everything_Mew process.

### Upgrade

```powershell
git fetch --tags
git checkout v0.3.0-rc.1
py -m pip install --upgrade .
```

Install the optional FastMCP compatibility path only when required:

```powershell
py -m pip install --upgrade ".[server]"
```

### Known limitations

- Everything_Mew is Windows-only and requires the standard Everything
  application and an architecture-matching official SDK DLL.
- `Everything.exe` owns the shared index and remains running independently of
  Codex. Its index memory is not per session and is not reduced by one-shot.
- A disabled MCP registration is unavailable; it does not wake automatically.
  Codex uses the installed skill to invoke the one-shot command explicitly.
- Active calls still have transient process and memory cost proportional to
  concurrency, even though idle per-session cost is zero.

## 한국어

### 요약

0.3은 Codex 권장 연동 방식을 세션 단위 MCP 서버에서 제한형 one-shot 명령으로
변경합니다. 각 도구 요청은 수명이 짧은 프로세스 트리를 시작해 기존 읽기 전용
도구 결과 하나를 반환한 뒤 종료합니다. OpenCode와 수동 MCP 호스트에서는 lite
stdio 호환 서버를 계속 사용하실 수 있습니다.

### 주요 변경 사항

- FastMCP 의존성 없이 `everything-mew-once`, `everything-mcp-once`,
  `python -m everything_mcp.oneshot` 진입점을 추가했습니다.
- UTF-8 JSON 요청 봉투 하나만 최대 65,536바이트까지 허용하며 후속 데이터,
  잘못된 JSON, 알 수 없는 도구, 유효하지 않은 인수를 거부합니다.
- 공개 읽기 전용 도구 네 개의 계약을 유지하고 별도 도구 구현 대신 기존 lite
  dispatcher를 재사용합니다.
- 성공은 종료 코드 `0`, 공개된 도구 오류는 `1`, 출력 결과를 신뢰할 수 없는
  호출 오류는 `2`로 구분합니다.
- Codex 스킬은 확인된 one-shot 실행기를 호출하며, 기존 MCP 등록은 명시적인
  롤백 설정으로 비활성 상태를 유지합니다.
- 실행기와 SDK DLL의 절대 경로를 고정하고 검증합니다. 설치기는 PowerShell
  리터럴에 경로를 넣기 전에 작은따옴표를 안전하게 이스케이프합니다.
- OpenCode와 수동 MCP 호환을 위해 `everything-mew-lite`와
  `everything-mcp-lite`를 그대로 유지합니다.

### 검증

- 로컬 Python 3.11에서 pytest 422건, Ruff, 소스·테스트 31개 파일에 대한
  strict mypy를 통과했습니다.
- wheel과 소스 아카이브 빌드에 성공했으며 SDK 바이너리, `.env`, 자격 증명,
  캐시, 로컬 증적이 배포 파일에 포함되지 않았음을 확인했습니다.
- 격리 설치한 wheel에서 두 one-shot 명령을 확인하고 FastAPI나 FastMCP 없이
  문법, 상태, 검색 스모크 테스트를 완료했습니다.
- 실제 SDK 상태에서 Everything 1.4.1.1032, `sdk-ipc`, 로드된 데이터베이스,
  예상한 x64 대상을 확인했습니다.
- 실제 one-shot 검색을 순차 10회와 동시 6회 수행한 뒤 남은
  Everything_Mew 프로세스가 없었습니다. Windows를 실제로 재부팅한 뒤에도
  호출 전후 유휴 Everything_Mew Python 프로세스는 0개였습니다.
- 독립 검토에서 남은 Critical 또는 Important 문제가 없었습니다.

검증 컴퓨터에서 활성 one-shot 프로세스 트리를 10회 측정한 중앙값은 임시 콘솔
호스트를 포함해 33.74 MiB Working Set, 15.15 MiB Private 메모리였습니다. 동시
6회 호출 합계는 202.34 MiB Working Set, 91.06 MiB Private 메모리였습니다. 이
수치는 해당 컴퓨터에서 관측한 값이며 고정된 자원 보장값이 아닙니다. 유휴 Codex
작업에는 Everything_Mew 프로세스가 남지 않습니다.

### 알려진 제한 사항

- Everything_Mew는 Windows 전용이며 표준 Everything 애플리케이션과 Python
  비트수에 맞는 공식 SDK DLL이 필요합니다.
- 공유 인덱스는 `Everything.exe`가 소유하며 Codex와 별도로 계속 실행됩니다.
  인덱스 메모리는 세션마다 복제되지 않으며 one-shot 전환으로 줄어들지 않습니다.
- 비활성화한 MCP 등록은 사용할 수 없으며 자동으로 깨어나지 않습니다. Codex는
  설치된 스킬을 통해 one-shot 명령을 명시적으로 호출합니다.
- 유휴 세션 비용은 0이지만 활성 호출에는 동시 실행 수에 비례하는 일시적인
  프로세스와 메모리 비용이 있습니다.
