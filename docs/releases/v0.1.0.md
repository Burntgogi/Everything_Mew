## English

### Summary

Everything_Mew 0.1.0 is the first Windows-only, read-only MCP integration for
finding indexed file and folder paths through Everything. It establishes the
four-tool public surface and the rule that Everything_Mew discovers candidates
while normal code and content tools inspect selected files.

### Included

- Four read-only MCP tools: `everything_status`, `everything_count`,
  `everything_search`, and `everything_syntax_help`.
- SDK/IPC as the primary local backend, with ES CLI and optional HTTP adapter
  support.
- The `everything-mew` command and the compatible `everything-mcp` alias,
  powered by the optional FastMCP server dependency.
- Path-first compact results, opt-in metadata, result limits, and broad-query
  safeguards.
- English and Korean setup guides for Everything and its official SDK.

### Runtime and limitations

- Windows and CPython 3.11 or newer are required by this baseline.
- Everything must be installed and running; Everything Lite cannot be used
  because it does not expose IPC.
- The primary `everything-mew` process imports FastMCP while idle. Hosts that
  keep one process per session should move to the 0.2 lite entrypoint.
- Version 0.2 strengthens query grammar, MCP error handling, SDK timeouts, and
  concurrent-session behavior while retaining the 0.1 command names.

## 한국어

### 요약

Everything_Mew 0.1.0은 Everything 인덱스로 파일과 폴더 후보 경로를 찾는 첫
Windows 전용 읽기 전용 MCP 연동입니다. 네 가지 공개 도구와 Everything_Mew는
후보 탐색만 담당하고 일반 코드·콘텐츠 도구가 선택한 파일을 검사한다는 역할
경계를 확립했습니다.

### 포함 사항

- 읽기 전용 MCP 도구 `everything_status`, `everything_count`,
  `everything_search`, `everything_syntax_help`.
- SDK/IPC 기본 로컬 백엔드와 ES CLI 및 선택적 HTTP 어댑터 지원.
- 선택적 FastMCP 서버 의존성으로 동작하는 `everything-mew` 명령과 호환 별칭
  `everything-mcp`.
- 경로 우선의 간결한 결과, 선택적 메타데이터, 결과 제한, 광범위 쿼리
  안전장치.
- Everything 및 공식 SDK의 영문·한글 설치 안내.

### 실행 환경과 제한 사항

- 이 기준판은 Windows와 CPython 3.11 이상이 필요합니다.
- Everything이 설치되어 실행 중이어야 합니다. Everything Lite는 IPC를
  제공하지 않아 사용할 수 없습니다.
- 기본 `everything-mew` 프로세스는 대기 중 FastMCP를 불러옵니다. 세션마다
  프로세스를 유지하는 호스트는 0.2의 lite 진입점으로 전환하는 것이 좋습니다.
- 0.2는 0.1 명령 이름을 유지하면서 쿼리 문법, MCP 오류 처리, SDK 시간 제한,
  동시 세션 동작을 강화합니다.
